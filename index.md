# NL-BioImaging Advanced Image Analysis Course 2026

Welcome to the training materials for the NL-BioImaging Advanced Image Analysis course,
held 21-24 September 2026 at Erasmus MC in Rotterdam.

Course information and registration: https://courses.microscopie.nl/?event_id=527

## Getting started
Before the course, work through the [preparation](preparation/preparation.md) page.
It explains how to install Python, git and the course environments.

Already have git and conda installed? Get the materials with:

```
git clone https://github.com/NL-BioImaging/NL-BioImageAnalysis-course2026.git
```

## Program
**[Day 1](day_1/README.md) - Foundations & tools** (Monday 21 September)
- Python ecosystem, Jupyter notebooks and image analysis libraries
- Image processing concepts: filters, thresholding and more

**Day 2 - Data access & AI introduction** (Tuesday 22 September)
- [OMERO and OME-Zarr](day_2/omero/README.md): accessing, managing and analyzing image data
- Computer vision & AI
- [Applying AI models in image analysis workflows](day_2/deep_learning/README.md)

**[Day 3](day_3/README.md) - AI segmentation & training** (Wednesday 23 September)
- Image annotation with napari
- BiaPy: accessible deep learning for bioimage analysis
- Preparing data and fine-tuning AI models

**[Day 4](day_4/README.md) - Reproducibility & wrap-up** (Thursday 24 September)
- Fractal: FAIR bioimage analysis at scale with OME-Zarr
- Agentic AI for developing image analysis workflows
- Data challenge and flash presentations
