# Setting up your computer

## 1. Install git

You can check if you have Git installed by running 

```
git config user.name
```

This should return your name or user name. If not install git.

## 2. Python and package managers
Many computers already have Python installed, but when working with Python is recommended to work in a virtual environment. First of all because you can define what version of Python you will use and because if you work on multiple project they all require different packages, so called dependencies.

There are several package managers that can help to setup the virtual environment.
- pip
- uv
- conda
- pixi

Install conda/miniforge from here: https://github.com/conda-forge/miniforge#install
