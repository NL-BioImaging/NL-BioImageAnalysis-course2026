
## Installation

### Windows
```
uv venv --python 3.11
source .venv/bin/activate
uv pip install zeroc-ice@https://github.com/glencoesoftware/zeroc-ice-py-linux-x86_64/releases/download/20240202/zeroc_ice-3.6.5-cp311-cp311-manylinux_2_28_x86_64.whl
uv pip install omero-py jupyterlab
```


### Linux
